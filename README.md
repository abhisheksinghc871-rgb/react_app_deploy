# Grain & Light (Vite + React)

## Local chalane ke liye
    npm install
    npm run dev

## GitHub Pages par deploy
1. GitHub par naya repository banao aur ye saari files push karo (branch: main).
2. Repo > Settings > Pages > Source: **GitHub Actions** select karo.
3. Push hote hi workflow chalega. 1-2 minute baad site live: https://<username>.github.io/<repo>/
